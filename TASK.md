# Aura Handbags – Premium Website Design & Development Prompt

## Objective

Build a **high-end, editorial-style single-page website** for **Aura Handbags**, an affordable premium handbag brand based in Meerut, India. The website must feel comparable to premium fashion brands like **Polène, Songmont, COS, Zara Home, Apple, and Massimo Dutti** while remaining authentic to Aura's identity.

The website should **not** resemble an AI-generated template, Shopify theme, or generic e-commerce landing page. Every section should feel intentionally designed with strong typography, generous whitespace, smooth animations, and elegant composition.
